# 四个默认相似K线模板：统计有效性验证 V1

- 截面：2026-07-28
- 实际分支：codex/template-analysis-validation-v1
- 标记：statistical validation review / not for model evaluation

## 先验假设与结论

### H1 百分位比分数原值更适合跨模板：支持

- 先验：原始 Pearson 只用于同模板排序；全市场百分位、最高分、中位数与前1%线更适合跨模板解释。
- 证据：四模板当前中位数/前1%线的最大跨模板差为 0.412；原值基线并不统一。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：首页保留

### H2 行业超额占比有解释力：支持

- 先验：行业相对全市场的超额占比，比 TopK 内原始占比更能识别形态供给偏向。
- 证据：3/4 个模板在 Top10/30/100 的第一行业保持一致；仍需同时看小样本敏感性。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：专门分析页

### H3 市值超额占比有解释力：较弱

- 先验：市值层级相对合格股票池的超额占比，可识别模板的规模偏向。
- 证据：2/4 个模板在 Top10/30/100 的第一市值层级保持一致；缺失市值单列。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：专门分析页

### H4 覆盖与集中度可区分供给宽窄：支持

- 先验：行业覆盖数、Top1 占比和 HHI 能区分广泛供给与少数行业挤压。
- 证据：当前 Top30 的行业覆盖为 8–17 个，HHI 为 0.124–0.364；能区分广泛供给与行业挤压。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：首页保留

### H5 四模板实际具有足够区分度：较弱

- 先验：若 Top10/30/100 的跨模板 Jaccard 重合率保持较低，四类标签才算在结果层面分开。
- 证据：当前 Top30 模板两两最大 Jaccard 为 30.4%；矩阵能直接暴露跨类混淆。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：专门分析页

### H6 异常事件二元标记可识别伪相似：不支持

- 先验：若涨跌停、停牌和异常单日的窗口二元标记不过度饱和，它们才适合合并识别事件驱动的相似路径。
- 证据：Top30 中单模板最高事件驱动占比为 100.0%，二元口径明显饱和；保留涨跌停、停牌、最大单日拆分字段，不保留合并总开关。
- 稳定性：已检查 Top10/30/100；历史异常口径未扩展
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：不采用（当前二元口径）

### H7 历史扩散能描述形态供给变化：支持

- 先验：固定模板下的分数线、合格数量、行业/市值扩散和榜单换手，可描述形态供给变化。
- 证据：历史合格数量最大变异系数 0.92，月度 Top30 换手中位数 96.7%；只作供给描述。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：专门分析页

### H8 需要识别强行排名：支持

- 先验：当最高分和前1%线相对本模板自身历史偏弱时，TopK 虽排满也应提示供给不足。
- 证据：当前相对自身历史同时偏弱：刚突破、健康上涨、回调转强、抛物线上升。
- 稳定性：已检查 Top10/30/100 与月末序列
- 少数异常股票审计：分布与占比均保留全量原始行，可追溯到股票；TopK 敏感性用于识别少数股票驱动。
- 产品建议：首页保留

## 方法与边界

- 核心算法：前复权 log-close；每个窗口独立 z 标准化；单窗口 Pearson。
- 排名：原始 Pearson 仅用于同模板内降序；行业、市值、成交量、异常标记均不参与排名。
- 历史：固定模板的事后回溯描述；不是模型评价、回测或预测结论。
- 明确未使用：未来收益、IC、策略表现、sealed final、联网行情。
- 行业：申万成员按 in_date/out_date 还原时点；重叠成员行单列审计。
- 市值：daily_basic 按每个截面 trade_date 读取 total_mv。

## 产品总建议

- 首页保留：全市场百分位、前1%线、最高分、合格数量、行业覆盖/集中度、弱供给提示。
- 专门分析页：行业与市值超额占比、TopK 敏感性、跨模板重合矩阵、历史扩散与换手、涨跌停/停牌/最大单日拆分字段。
- 不采用：统一“90分合格线”、用原始 Pearson 跨模板比较、合并异常事件二元总开关、把历史固定模板回看写成模型评价或预测。
