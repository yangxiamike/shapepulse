# 手动跟踪市场 v1.1 验收标准

日期：2026-07-16

## 1. 通过门槛

只有同时满足下列条件，v1.1 才能宣布完成：

- 构建、lint、前端测试、后端测试全部通过。
- 需求说明中的必做功能没有 P0/P1 未关闭问题。
- 性能预算全部达标。
- 1600×1000、1280×900、1024×800 三档真实 Chrome 验收通过。
- 三类形态各抽样至少 5 只并完成逐图视觉检查。
- 截图、性能原始数据、复现步骤和结论已写入最终报告。
- README、CHANGELOG 和 Git 提交记录完整，未推送远端。

## 2. 功能检查表

### 看板

- [ ] 三个类别可用鼠标点击和键盘 Enter/Space 进入。
- [ ] 三类分别显示自己的 Top 50，排名从 1 独立开始。
- [ ] 综合榜和分类榜切换后内容、数量与排名不混淆。
- [ ] “查看全部”能显示完整结果，并可稳定滚动/分页。
- [ ] 行情、估值、ST、复权日期与警告可见。
- [ ] “较昨日”来自历史；无记录时显示“暂无对比”。
- [ ] 候选详情显示真实理由、指标、可读 K 线和成交量。
- [ ] 空结果、服务错误、重试和筛选进度可用。
- [ ] 保存、待判断可添加/移除，已查看和历史展示具体记录。

### 行情终端

- [ ] 从看板打开后默认日 K 为 95–115 根。
- [ ] 日/周/月/季/年 K 聚合边界与 OHLCV 语义正确且结果不同。
- [ ] 范围选择、滚轮缩放、拖动与十字光标可用。
- [ ] 趋势线、水平线、文本、测量、清除画线有可见结果。
- [ ] 未实现功能不可点击，悬停/聚焦能看到原因。
- [ ] 形态标签展示当前股票事实、指标、规则、日期、警告和历史。
- [ ] 形态空状态区分未计算和无匹配。
- [ ] 形态标签只有到看板查看当前股票记录的跳转，没有推荐流。
- [ ] 自选可真实添加/移除，刷新后保持。
- [ ] 详情不是占位，错误可重试，没有 hydration mismatch。
- [ ] 1024 下右栏功能仍有可访问入口。

### 信息架构与数据

- [ ] 只有一个“本地行情”导航入口。
- [ ] 代码库和网络面板中没有外部行情源。
- [ ] 本地相对 `data_dir` 不受启动目录影响。
- [ ] 缺估值、ST/复权滞后都有可见警告。
- [ ] 看板与行情页只共享代码、形态事实和跳转。

## 3. 视觉检查

每档视口检查：

- [ ] 无页面级意外横向溢出、遮挡、不可达控件和截断图表。
- [ ] 正文建议 ≥14px、表格 ≥13px、图表坐标/工具栏 ≥12px。
- [ ] 键盘焦点清楚，点击态/禁用态/加载态能在 100ms 内看到。
- [ ] 1600 看板右侧图表有效绘图区 ≥420×280。
- [ ] 1280 看板采用上下布局，图表保持可读。
- [ ] 1024 行情右栏通过抽屉或底部面板访问。
- [ ] K 线涨跌色、均线、价格轴、时间轴、成交量轴和柱体可分辨。
- [ ] 暖白、近黑、薄荷绿、蓝和荧光黄与批准图一致，层级克制。

形态抽样：

- 突破启动：至少 5 只。
- 上升趋势回调：至少 5 只。
- 区间下沿反弹：至少 5 只。

每只检查标签、分类排名、理由、分数、K 线/成交量和形态描述的一致性；发现算法事实与视觉描述冲突即失败。

## 4. 严重度

| 等级 | 定义 | 发布判定 |
|---|---|---|
| P0 | 数据源越界、数据破坏、页面完全不可用、错误行情 | 必须修复 |
| P1 | 核心流程失败、分类混淆、聚合错误、性能硬指标失败、关键视口不可用 | 必须修复 |
| P2 | 次要流程或明显视觉/可访问性问题，有替代路径 | 应修复；残留需用户确认 |
| P3 | 轻微文案、间距或非关键一致性问题 | 可记录为残余风险 |

## 5. 证据要求

最终报告每个失败/修复项包含：

- 复现步骤。
- 实际结果与预期结果。
- 严重度 P0–P3。
- 修复提交或残余风险。
- 对应截图绝对/仓库相对路径。

禁止仅以 DOM 尺寸或自动化通过代替视觉检查。
