# 形态分类算法 V2：三类定义卡 Draft 2

> 本版吸收 C1 的 18 个匿名样本标注，仅用于 C2 定向校准。  
> 仍然只判断 T0 当下的形态，不使用未来 K 线、未来收益或交易策略结果。

## 统一分值

| 分值 | 判断 |
|---|---|
| 0 | 不相关，或存在核心矛盾 |
| 1 | 有局部影子，但关键结构缺失或损伤明显 |
| 2 | 类别成立，但质量或确认程度并不理想 |
| 3 | 高度相关，可作为代表性模板 |

## 刚突破

- **0分：**没有有效突破。
- **1分：**只有局部影子，例如下跌趋势反弹、平台不清或单日突拉。
- **2分：**突破清楚，但发生在 T0 当天尚未确认；或者确认质量略弱。
- **3分：**清晰突破已发生 1～3 根 K 线，随后仍守住突破位，量价和背景结构协调。

突破当天不查看未来数据。只有当评分日已经处于突破后的第 1～3 根 K 线时，才判断是否守住。

## 健康上升趋势

- **0分：**中期趋势已经转弱、长期横盘或只是下跌后的反弹。
- **1分：**仅有局部上升，趋势连续性和结构质量较弱。
- **2分：**健康趋势成立，但存在旧前高受阻、过度延伸或波动偏大等缺陷。
- **3分：**多周期趋势连续、回撤受控，且未在重要旧前高处明显停滞。

接近更早的显著前高只是软扣分；若有效突破并守住，则不扣分。

## 回调转强

- **0分：**回调前没有上升基础、仍在创新低，或已经长期拖成区间。
- **1分：**能看出上升后回调，但过深、过急、过久或转强证据很弱。
- **2分：**回调转强结构成立，但深度、时间或确认质量并不理想。
- **3分：**此前趋势清楚，回调浅至适中、时间受控，并出现明确转强确认。

回调深度、回调速度和持续时间分别扣分；不能只用一个回撤百分比决定。

## “大区间”的处理

“大区间”不新增为第四个用户类别，而是共用背景事实：

- 在区间底部但没有三类结构：三类均可为 0。
- 运行到区间顶部但没有突破：健康趋势适当扣分，刚突破不成立。
- 从大区间顶部有效突破并守住：可以成为高质量刚突破。
- 上升或回调拖得过久并转成横盘：降低健康趋势和回调转强分数。
