# 形态分类 V2 最终定义卡

> 定义版本：`shape-v2.0.0-final-definition`
>
> 依据：C1/C2/C3 共 54 条匿名人工校准标注
>
> 状态：定义已闭合；算法仍是研究基准，未进入正式 API 或前端

## 共通规则

- 三类是三个独立相关度，不是互斥分类；同一段走势可以同时属于多类。
- 每类独立打 `0~3` 分：`0` 为不相关或存在核心矛盾，`3` 为高度代表。
- 只看评分日及以前约 120 根 K 线与成交量，不显示名称、代码、行业、日期或未来。
- 所有价格统一归一化，成交量保留相对结构。
- 不预测未来收益，不计算 IC，不给交易策略。

## 刚突破 `fresh_breakout`

定义：价格此前没有处于持续上升趋势，而是在长期横盘、底部震荡、区间低位或持续阴跌后，突然打破原有结构并转强。关键不是“又创新高”，而是从“不涨或走弱”切换为明显向上。

评分锚点：

- `0`：没有突破清晰结构；普通下跌反弹、区间内冲高或突破后立刻高量回撤。
- `1`：有局部突破影子，但对象、力度、背景、量价或时效性有明显缺陷。
- `2`：突破结构清楚，但仍在突破当天、确认略弱，或已经离突破时点稍久。
- `3`：突破后约 1~3 根 K 线仍强且守住突破位，接近过程、连续性和量价协调。

时间规则：

- 突破当天原则上最高 `2` 分。
- 突破后 `1~3` 根 K 线确认且未立刻走弱，才可能 `3` 分。
- 约 `5~15` 根 K 线后逐步衰减；是否仍相关由当前结构决定。

核心矛盾：

- 没有可辨认的压力区、前高或整理范围。
- 突破前已经形成持续上升趋势，只是短暂调整后再次创新高。
- 突破后明显跌回突破位下方。
- 只是普通下跌反弹，且没有打破局部结构。
- 突破发生已久，已经演化成其他形态。

长期横盘、底部震荡、区间低位和持续阴跌是刚突破的主要前置状态。旧前高不是一刀切否决项；如果原上升趋势已被足够长的横盘或走弱真正重置，随后突然上破，仍可算刚突破。若原上升趋势始终完整，则应由健康上升趋势或回调转强解释。

## 健康上升趋势 `healthy_uptrend`

定义：评分日处于持续、有序且不过度失真的上升结构中；高点和低点总体抬高，回撤未破坏主要结构。

评分锚点：

- `0`：中期趋势转弱、长期横盘，或只是下跌后的反弹。
- `1`：仅有局部上升，连续性和结构质量较弱。
- `2`：健康趋势成立，但存在旧前高受阻、过度延伸或波动偏大等缺陷。
- `3`：多周期趋势连续，高低点总体抬高，回撤受控。

核心矛盾：

- 中期高点与低点持续下移。
- 持续跌破主要趋势支撑且未收复。
- 结构主要由极端跳涨或单点尖峰构成。
- 上升已经演化为缺乏方向的大区间。

## 回调转强 `pullback_strengthening`

定义：此前已有上升基础，随后发生未完全破坏主结构的真实回调，并在评分日附近出现止跌、收复或动能重新转强。

评分锚点：

- `0`：回调前没有上升基础、仍在创新低，或已经长期拖成区间。
- `1`：能看出上升后回调，但过深、过急、过久，或转强证据很弱。
- `2`：回调转强结构成立，但深度、时间或确认质量并不理想。
- `3`：此前趋势清楚，回调浅至适中、时间受控，并出现明确转强确认。

核心矛盾：

- 回调前没有可辨认的上升基础。
- 评分日仍在连续走弱或创阶段新低。
- 回撤已经破坏中期趋势，只剩弱反抽。
- 回调持续过久并已演化为大区间。

深、快回撤通常为 `0`；长时间拖延通常为 `0~1`。

## 样本与置信限制

三轮校准的 `2/3` 分样本数分别为：

- 刚突破：10 条，其中 `3` 分仅 1 条。
- 健康上升趋势：13 条，其中 `3` 分 9 条。
- 回调转强：9 条，其中 `3` 分仅 2 条。

因此定义可以封口，但统计模板不能声称成熟。第一版只允许用于基准排名和 tuning 评审。
