# 形态分类算法 V2：三类定义卡（待评审）

> 状态：`shape-v2.0.0-draft1`，仅用于定义评审和匿名样本校准。  
> 范围：只判断评分日当下的 K 线形态及相似度，不使用评分日后的数据，不预测收益。

## 统一标注方式

每个匿名样本都要对三个类别**分别**打分，允许一张图同时与两类相关，不做“只能三选一”。

| 分值 | 判断 |
|---|---|
| 0 | 不相关，或存在该类核心矛盾；若排到榜单前列属于严重错误 |
| 1 | 有局部相似，但缺少关键结构或有明显缺陷 |
| 2 | 相关且可用，主要结构成立，但不是理想代表 |
| 3 | 高度相关，可作为该类别的代表性模板样本 |

标注只看 T0 及以前约 120 个交易日。不得查看股票名称、代码、行业、真实日期和未来 K 线。

## 1. 刚突破

### 一句话定义

评分日附近刚刚有效越过一段可辨认的压力区，仍处于突破初段，而不是已经远离平台后的加速末段。

### 关键证据

- 突破前存在可辨认的整理或压力区。
- 收盘价站上压力区，或突破后少量交易日内仍守住。
- 量能与价格行为至少不互相矛盾；放量是加分项，但不单独决定类别。
- 离中期均线和突破位的距离仍处合理范围。

### 核心矛盾

- 没有可辨认的压力区或突破位。
- 评分日已经明显跌回突破位下方。
- 突破发生已久且价格严重过度延伸。
- 实际是下跌趋势中的单日反弹。

### 与另外两类的边界

- “健康上升趋势”可以在突破后继续成立，但若突破已过去较久，“刚突破”相关度应下降。
- “回调转强”必须先有上升和回调；没有回调过程的突破不应因为短线转强而误标。

## 2. 健康上升趋势

### 一句话定义

评分日处于持续、可辨认且不过度失真的上升结构中；高低点、均线、斜率和回撤共同支持趋势仍健康。

### 关键证据

- 中短期斜率为正，且走势不是仅靠一两根异常 K 线抬高。
- 价格大体运行在中期均线之上，均线结构有序。
- 阶段回撤受控，没有破坏主要上升结构。
- 波动、乖离和量价状态不过度极端。

### 核心矛盾

- 中期趋势斜率已经转负。
- 价格持续跌破主要趋势支撑且未收复。
- 结构主要由极端跳涨或单点尖峰构成。
- 实际是长期下跌后的弱反弹。

### 与另外两类的边界

- 刚突破的股票也可能是健康趋势，但“健康趋势”不要求评分日刚好发生突破。
- 回调转强是健康趋势中的一个更具体阶段；若确有“上升—回调—重新转强”，两类可以同时给高分。

## 3. 回调转强

### 一句话定义

此前已有上升基础，随后发生真实但未破坏主结构的回调，评分日附近出现止跌、收复或动能重新转强的证据。

### 关键证据

- 回调前存在可辨认的上升段。
- 中间确实发生回撤，而不是一路直线上涨。
- 评分日附近出现更高低点、均线收复或短期动能转正等转强证据。
- 转强发生时主要趋势尚未被严重破坏。

### 核心矛盾

- 回调前没有上升基础。
- 评分日仍在连续走弱或创阶段新低。
- 回撤已经破坏中期趋势且只是弱反抽。
- 没有经历回调，实际只是刚突破或持续上行。

### 与另外两类的边界

- “下跌后反弹”不是“回调转强”，前提必须是此前已有上升趋势。
- 若回调后同时越过新压力位，可以对“刚突破”和“回调转强”分别高标。

## 标注时的最小记录

每张图需要保存：

- 三个类别各自的 0～3 分。
- 任何被判定为 0 分的核心矛盾。
- 对边界样本或分歧样本的一句说明。
- 标注者编号；不需要填写股票身份。

## 本轮待确认

1. “刚突破”是否允许突破后的 1～3 个交易日仍记 3 分，还是只认评分日当天。
2. “健康上升趋势”是否接受短暂跌破 20 日均线但未破坏 60 日结构。
3. “回调转强”的最低转强证据：只需短期动能翻正，还是必须收复关键均线/前一局部高点。
4. 同一样本允许多类同时 2～3 分，这一规则是否确认。
