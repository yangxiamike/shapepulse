# 形态 V2：健康上升趋势历史区间挖掘

## 结论

`template-discovery-v1` 不是最终模子。它虽然来自独立 `template` 分区，但每只股票只取
截至 `20260727` 的最近 120 根K线，仍然存在“固定看尾端”和“只看近60日回撤”的偏差。

用户复核后明确纠正：

- `S-504EF8F6B319` 的整段最大回撤为 `31.72%`，最差10日为 `-28.85%`，降为至多1分。
- `S-E330AB557500` 的整段最大回撤为 `11.61%`。虽然比上一条轻，但视觉回撤仍偏大，
  不作为健康上升趋势代表模子，降为至多1分。

旧产物保留作错误审计，不覆盖、不删除；新结果进入独立的
`template-discovery-v2/healthy-uptrend-segments`。

## v2 做了什么

- 只使用本机 zer0share 快照 `20260727`，未联网、未补数。
- 只扫描尚未进入校准和 tuning 评审的独立 `template` 分区。
- 对每只证券的历史评分日滚动截取 120 根K线；片段只含评分日及以前数据。
- 共扫描 `2,577` 只证券、`87,741` 个历史区间。
- 同一只证券只保留一个得分最高区间，防止相邻日期和同一段形态重复充数。
- `619` 只证券至少有一个区间通过严格路径门槛；最终保存60个候选供视觉检查。

这批数据属于模板发现，不是 tuning，也不是封存最终评估。最终评估集没有参与。

## 新增的路径约束

旧版主要依赖共享事实中的近60日回撤。v2 直接从完整120根K线的可见路径增加：

- 整段最大峰谷回撤；
- 近60日最大峰谷回撤；
- 最差5日和最差10日变化；
- 每10根K线锚点的抬高比例；
- 末端20日涨幅占整段涨幅的比例。

健康趋势候选的核心硬矛盾包括：

- 整段最大回撤超过 `14.5%`；
- 近60日最大回撤超过 `12%`；
- 最差10日低于 `-13%`；
- 完整窗口涨幅、连续度或前段上升基础不足；
- 涨幅过度集中在末端；
- 中期波动过高。

硬门槛只是候选池底线，不等于代表模子标准。实际进入前60的整段最大回撤中位数为
`7.48%`，最大为 `10.68%`；AI 视觉复核又排除了依赖大跳空、单点脉冲或尾端集中拉升
的片段。

## 当前视觉短名单

- 代表模子：10条，均为暂定3分。
- 边界片段：5条，暂定2分。
- 明确不作为代表模子：5条，暂定0至1分。

用户于 `2026-07-28` 明确认可代表模子的选择方向。因此，这10条从
`ai_visual_provisional` 升级为 `user_direction_confirmed`，可以用于建立低置信度的第一版
健康上升趋势统计模板。它们仍不属于封存评估样本，也不代表模型已经成熟。

如果后续用户纠正这些模子，可以更新模板和 tuning，但不能据此反复修改封存最终评估
结果。
