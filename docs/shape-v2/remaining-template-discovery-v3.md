# 形态 V2：刚突破与回调转强历史模子 v3

## 为什么另外两类也要单独选模子

三类形态允许重叠，但判断依据不同：

- 刚突破关心压力结构、突破年龄、突破后保持、量价和大区间位置。
- 健康上升趋势关心完整窗口的连续抬高、回撤和波动。
- 回调转强关心前段上涨基础、真实回调的深度和时长、低点位置及当前收复。

因此不能用健康上升趋势的好模子或门槛代替另外两类。三类共享同一套事实和历史区间
扫描，但使用三套独立筛选器、视觉标准和统计模板。

## 可复现脚本

当前流程已经收敛为仓库脚本：

- `scripts/shape_v2_segment_mining.py`
  - 提供完整路径回撤、近期峰谷回调、低点年龄和收复比例等共享区间事实。
- `scripts/shape_v2_remaining_template_mining.py`
  - 一次扫描同时运行刚突破、回调转强两套独立评分器。
  - 每只股票、每个类别只保留一个历史区间。
  - 生成匿名样本、图表、排名、公开清单和私有泄漏审计。
- `scripts/shape_v2_remaining_template_shortlists.py`
  - 把候选按代表、边界、明确剔除整理成用户可扫读页面。

现阶段不制作跨项目 Skill。原因是类别规则仍会根据用户视觉反馈修正；仓库脚本更适合
版本化保存候选、错误和审计。三类定义、门槛和输出格式稳定后，再将“扫描—审计—
视觉短名单—模板统计”的通用流程封装为 Skill。

## v2 第一轮暴露的问题

### 刚突破

第一轮Top24混入多条普通下跌反弹和大区间内部冲高。它们虽然越过20日局部高点，但：

- 仍位于完整120日区间的中下部；
- 距离60日前高和旧高较远；
- 60日背景仍弱；
- 没有真正打破更有意义的结构。

第一轮产物保留在 `template-discovery-v2` 作错误审计，不作为模子。

### 回调转强

第一轮主要使用评分日距60日高点的回撤，混入一些已经恢复到新高、看不出近期真实
回调的片段，也混入大跳空和宽幅震荡。

第一轮同样保留作错误审计。

## v3 修正

### 刚突破新增

- 完整120日区间位置；
- 相对60日前高的距离；
- 相对旧高的距离；
- 60日涨幅和斜率背景；
- “仍困在大结构下方”和“弱背景普通反弹”核心矛盾。

突破当天仍通常只作为边界；清晰突破后1至3根仍守住，才优先进入3分代表候选。

### 回调转强新增

直接在最近40根收盘路径中识别：

- 最近一次真实峰谷回调深度；
- 回调低点距评分日的根数；
- 从低点到评分日已收复的比例。

没有可见回调、回调过深、低点太久、尚未开始恢复，或已经完全演变成新一轮上涨的
片段会被降级或剔除。

## 2026-07-28 最终边界确认

用户确认三类边界可压缩为：

- 健康上升趋势：一直涨得健康。
- 回调转强：涨过、回调了、现在重新转强。
- 刚突破：原来没在涨，现在突然开始涨。

因此刚突破继续收紧：高位上升趋势中的短暂停顿和再次创新高，不再作为3分刚突破模子；
只有长期横盘、底部震荡、区间低位或持续阴跌已经形成独立前置状态，随后突然打破结构，
才进入刚突破高相关区。较早的上涨若已被足够长的横盘或走弱真正重置，不作机械否决。

用户评审页后续默认只展示3分代表模子。1分和2分仍保留为算法内部的反例与边界材料，
不再要求用户逐条复核。

## 刚突破最终收紧与 v7

视觉复核 v5 候选时，又发现两种较隐蔽的趋势延续：

- 总涨幅不夸张，但突破前约40根K线已经连续抬高；
- 中途有回撤，但约100根K线的整体斜率和拟合度已经形成上升趋势。

因此最终评分同时检查突破前40、60和100根K线。只要较短或较长窗口已呈现成熟上升，
即使末端再次打破20日高点，也触发 `already_established_uptrend`，不进入刚突破3分模子。
长期平台或走弱若已真正重置旧趋势，则不作机械否决。

v7 使用本机 zer0share 快照 `20260727` 重扫 `87,741` 个历史区间、`2,577` 只证券，
生成60个模板候选；私有审计未发现未来数据或切分泄漏。该集合角色仍是 `template`，
没有访问封存最终评估集。

当前统一入口 `outputs/shape-v2/template-current/index.html` 默认只展示三类各10张3分模子。
1分和2分材料继续保存在各轮历史页面和私有审计中，不删除、不覆盖。
