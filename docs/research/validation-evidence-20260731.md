# A/B 状态系统验证证据索引

本页汇总 README“验证结论与系统定位”所引用的三组研究证据。它只保留结论、关键数字和产品边界，不复制完整实验过程，也不构成投资建议。

## 两状态—行业兴衰扩样严谨验证

### 结论

个股“刚突破（A）→趋势承接（B）”状态转换成立；行业层只得到部分支持，不能把现版本解释成完整的行业生命周期或轮动预测系统。

### 关键证据

| 指标 | 结果 |
| --- | ---: |
| 40 日风险集 | 15,841 |
| 实际 A→B 转换率 | 39.31% |
| 共同时间移位 null | 5.19% |
| 绝对超额 | 34.11pp |
| 首次进入 B 的中位时间 | 14 个交易日 |
| B 状态中位持续时间 | 11 日 |

严格双日确认、Top50/Top100、年份拆分、反向转换、提前 60 日 placebo、匹配和离散 hazard 等检查没有推翻个股层结论。不过，匹配并不完美，结果仍应表述为稳定的条件关联，而不是 A 导致 B 的因果关系。

### 未通过的行业能力

- **行业 A 涌现未通过：**A 异常集中没有稳定领先未来 B 广度变化。
- **行业高转化主线确认未通过：**高转化行业的未来 B 持续率没有优于低转化行业，部分口径方向相反。
- **行业降温仅部分支持：**可作为状态研究线索，证据不足以独立产品化成预测警报。

### 边界

- 较早样本存在固定模板前视，只能称回溯或时间外稳健性。
- 发现样本复用，不是最终实时样本外确认。
- 未证明交易收益。

## 主线走弱与相对替代验证

### 结论

已确认主线内部走弱后，外部 A 兴起或后续外部 B 确认，没有提供足够稳定的增量证据。因此，当前不能把这组状态写成资金迁移、板块轮动或“下一主线”识别。

### 关键证据

- 样本识别到 59 个已确认主线内部走弱事件，覆盖 29 个行业。
- 其中 24 个事件同时出现外部 A 兴起，9 个随后获得外部 B 确认。
- 外部 A 相对“仅内部走弱”的未来 10/20/40 日增量分别为 -3.4pp、-4.8pp、+2.7pp，置信区间均跨过零。
- 多组强度与集中度规格没有形成足够稳定、可升级的结果。

### 正确用途

内部 B 与 A 同时下降，可以显示为“内部走弱观察”；其他行业 A 上升只能作为相对替代标签。只有未来 B 也上升后，才能追加“外部 B 确认”，但这不是实时预测信息。

### 边界

- 不代表资金已经迁移。
- 不预测谁是下一主线。
- 不解释政策、产业或其他因果原因。
- 不证明可交易收益。

## 主线退潮时序验证

### 结论

行业正式 B 不是价格退潮的高覆盖必要条件。它在命中的事件中更像滞后的状态确认，而不是未来继续下跌的预测警报。A 虽然机械上出现更早，但没有带来稳定增量准确率，也没有识别出“修复”。

### 关键证据

| 指标 | 结果 |
| --- | ---: |
| 独立价格退潮事件 | 44 |
| 正式 B 覆盖率 | 68.2%（30/44） |
| 命中事件中位滞后 | 18 日 |
| B 确认时已完成跌幅中位数 | 65.7% |
| B 后价格继续走弱精确率 | 14.9%（25/168） |

正式 B 覆盖率低于冻结的 70% 下限，更未达到 85% 高覆盖门槛。阈值放宽虽然会提高覆盖率，也会同步增加警报。命中事件中，正式 B 通常晚于价格峰值超过 10 个交易日，因此应描述为“已确认降温”。

### 龙头与 A 的结果

- 机械主龙头的 B 走弱通常早于行业正式 B，但随机龙头安慰剂的时序接近，特异性偏弱。
- 不能把龙头退出 B 解释成导致行业退潮的因果传导。
- 动态 A 回升没有降低未来继续降温概率，A 修复未通过升级门槛。
- A 对未来价格走弱的增量准确率没有达到冻结门槛。

### 正确用途

- 行业 B：描述当前主线健康、松动和已确认降温。
- 龙头退出 B：只作辅助观察。
- A：保留为个股候选排序和观察标签，不作行业早期预警。

### 数据边界

- 研究窗口为 2021-01-04 至 2026-07-29。
- 行业价格由历史成分股、当日合资格股票等权合成，不是正式申万指数。
- 结果只描述条件关联，不是因果结论、未来涨跌预测或收益承诺。
