## 2. 编码前主动问题清单

### P1：综合榜丢失多形态事实

- 本地筛选的三个分类各返回 Top 50。
- 当前本地事实中，`002821.SZ 凯莱英` 同时位于突破启动与上升趋势回调结果。
- 综合榜 `results` 的 50 条记录全部没有 `matches` 字段。
- 原因是后端组合结果时主动剔除 `matches`，前端 `Stock` 映射和看板也只保留主形态。
- 这不是“本地事实只有一个”，而是 API 装配和列表/详情渲染丢失。

### P2：两点落笔缺失

- 选择“线段”后，只点击一次画布，`data-drawings` 立即从 0 变成 1，模式也立即回到选择状态。
- 当前所有两点类工具仍采用按下、拖动、松开完成。
- 线段当前几何边界本身正确；趋势线、射线和线段的像素边界也确实不同，修复不能破坏这一点。

### P3：斐波那契没有设置入口

- 创建并选中斐波那契回撤后双击图形。
- 页面中 `role=dialog` 数量为 0。
- 绘图模型只有硬编码全局比例，不能逐项开关，也不能新增或删除自定义比例。

### P4：没有字体大小功能

- 看板与行情页均无字体/字号入口。
- 无对应持久化键，也没有图表文字同步机制。

### P5：分隔器只有横向

- 行情页主图/右栏分隔器横向拖动后，右栏 `360px → 445px`，主图同步变窄。
- 同一分隔器只做纵向拖动时，主图和右栏高度都不变。
- 看板候选/详情分隔器横向可改宽度；纵向拖动时工作区高度始终为 `664px`。
- 两页均没有“自由调整/仅左右比例”切换入口。
- 结合用户“能拉动但不能自由上下拉动”的描述，当前最直接对应的是候选/详情工作区：它需要在自由模式中同时提供工作区高度调整，并在窄屏堆叠时退化为上下分隔；仅左右模式保持桌面比例调整。

### P6：真实文字与控件几何问题

- 四档视口均出现状态卡文案“仅使用 zer0share 快照”自身宽度不足。
- Top K 控件在四档视口均有 `scrollWidth > clientWidth`。
- Top 50 标题、圆环数字和三张形态统计卡的大号数字存在行盒高度小于内容高度。
- 1600 宽看板表格最后一列默认落在内部横向滚动区之外；1366/1024 更明显。允许表格内部横滚，但必须保留清楚的滚动提示和完整表头语义。
- 1024 看板详情操作按钮仍有轻微祖先裁切（可见比例约 0.93）。
- 行情绘图工具栏在 1600、1366、1024 高度下需要纵向滚动，但滚动条被隐藏；1366 起“文本/测量/操作”按钮默认落出可视区。

### P7：仍需锁定的已有正确能力

- Top K 默认 50，完整名单展开后仍应是 50。
- 三种线当前画布边界不同：趋势线贯穿两端；射线从第一点经第二点向前；线段只连接两锚点。
- 形态股票列表当前可返回完整分类池，连续键盘切股会滚动活动项。
- 历史快照只在用户主动保存时产生，修复不得改变这一语义。
