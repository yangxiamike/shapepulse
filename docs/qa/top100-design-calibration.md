# Top100 行业宽度与真实 K 线工作流：交互/视觉设计校准

> 角色：独立交互/视觉设计校准，不参与应用代码实现。
> 校准分支：`codex/top100-kline-workflow-v4`
> 校准对象：行业宽度、模板库、`/templates/new`、行情详情。
> 基本边界：四个模板与相似算法不变；不使用未来表现解释匹配质量。

## 1. 结论先行

本轮应把四个页面整理成一条单向、可返回的工作流：

```text
行业宽度（看 Top100 分布）
  └─ 点击行业 → 当前入选 / 新进 / 保留 / 退出
       └─ 点击股票 → 行情页（保留 template 与列表上下文）

模板库（浏览、分析、管理）
  ├─ 点击 Top 股票 → 行情页（保留 template 与列表上下文）
  └─ 新建模板 → /templates/new
       └─ 搜索股票 → 框选真实历史 K 线 → 命名并保存 → 回到模板库新模板
```

必须统一的产品判断：

1. 行业图的面积永远只表示“当前 Top100 中该行业的股票数”，不能在任何切换中改为 5 日变化量。
2. 行业入选率是补充强度指标，不参与面积；始终写明分母为“该行业当日可选股票数”。
3. “当前宽度”和“最近变化”是两个并列信息区，不做会改变面积语义的视图切换。
4. 新进、保留、退出必须同时有文字/数字/形状，颜色只做辅助。
5. 模板详情、候选缩略图、创建页预览、行情对照均使用真实本地前复权 K 线；抽象归一化线不再承担主展示。
6. 行情页只看行情与对照，不再出现保存模板入口。
7. “匹配到抛物线前段”只能解释当前选中窗口处于哪个形态阶段，不能外推市场是否存在抛物线行情。

## 2. 当前实现需要纠偏的设计点

这些是开发验收时应主动回查的现状差异：

- 行业宽度页当前仍突出 `0.80` 观察线、线上/相对偏低和分隔条；主产品口径需全部退出。
- 当前 Treemap 是按行拼接的近似布局，并且“最近变化”会把面积切换为变化绝对值；需替换为真正的 squarified treemap，且面积语义固定。
- 当前行业详情主要只有数量时间序列，缺少当前 Top100 股票列表以及新进/保留/退出紧凑列表。
- 模板库顶部仍有手输代码与日期的创建表单；需移到独立页面。
- 模板详情当前使用归一化抽象线；需改为真实前复权 K 线，并明确窗口起止。
- 模板 Top 股票行缺少候选窗口迷你 K 线。
- 行情页当前有“保存区间”和“保存当前区间为模板”；需删除。
- 行情页目前存在面板收起，但没有面向普通用户的“顶部摘要 + 工具区”两档紧凑控制。

## 3. 全局信息层级与视觉基线

### 3.1 字体层级

沿用现有字体调节能力，以下数值指“标准字体”基线：

| 层级 | 1440 / 1024 | 390 | 用途 |
|---|---:|---:|---|
| 页面标题 | 30–34 px / 800 | 26–29 px / 800 | 行业宽度、模板库、新建模板 |
| 模块标题 | 19–22 px / 750 | 18–20 px / 750 | 当前宽度、最近变化、真实 K 线 |
| 核心数字 | 24–32 px / 800 | 22–28 px / 800 | Top100 数量、相似度、行情价格 |
| 行/卡片主文本 | 14–16 px / 700 | 14–16 px / 700 | 股票名、行业名 |
| 辅助说明 | 12–13 px / 500 | 12–13 px / 500 | 分母、日期、代码、单位 |

要求：

- 最小可读正文 12 px，不用 10–11 px 承载口径、日期或分母。
- 数量后明确“只”，入选率后明确“%”，相似度保持 3 位小数。
- 日期统一 `YYYY-MM-DD`；窗口显示“起始 — 结束 · N 个交易日”。
- 辅助灰文字与背景对比度至少 4.5:1；不可用态也不能淡到无法阅读。

### 3.2 通用交互状态

- 桌面按钮/股票行 hover：背景或边框明显变化，但不产生布局位移。
- 键盘 focus：统一 2 px 深色或高对比色外环，外偏移 2 px；不能只依赖浏览器不稳定的默认细线。
- 当前选中：使用“左侧实线/外框 + 背景 + `aria-current`”，不能只变色。
- 最小点击区：桌面 36×36 px；触屏 44×44 px。
- 整行可点击时，内部不要再嵌套相互冲突的链接；重命名/删除等独立操作必须有自己的明确按钮。
- loading、空态、错误态都占据稳定高度，避免图表加载前后页面大幅跳动。

### 3.3 颜色建议

不要沿用红涨绿跌的行情语义表达行业进出。建议：

| 状态 | 颜色辅助 | 非颜色编码 |
|---|---|---|
| 新进入 | 蓝 `#176CBA`，浅底 `#E8F2FB` | `＋ 新进 N`、实心圆/实心短条 |
| 保留 | 青绿 `#24745A`，浅底 `#E7F2ED` | `＝ 保留 N`、横线/中性短条 |
| 退出 | 橙褐 `#9A4F13`，浅底 `#FBECDD` | `－ 退出 N`、空心圆/描边短条 |
| 无变化 | 中性灰 `#656B68` | `＝ 0` |

所有正文落在浅色底上时应使用深色文字。图例必须直接写“新进 / 保留 / 退出”，不能只放三个色块。

## 4. 行业宽度主页面

### 4.1 首屏布局

1440 桌面建议顺序：

```text
页面标题 + 数据日期 + 一句话口径
四模板切换（当前模板名称必须一眼可见）
概览条：Top100 固定口径 | 最宽行业 | 5日新进最多 | 5日退出最多
┌──────────────── 当前宽度：Squarified Treemap ────────────────┐
│ 面积 = 当前 Top100 数量；块内 = 行业名 / N只 / 入选率 x.x%  │
└───────────────────────────────────────────────────────────────┘
┌────────── 当前行业详情 / 股票列表 ──────────┬── 最近变化 ──┐
│ 当前进入 Top100 的股票，可进入行情           │ 新进/保留/退出 │
└──────────────────────────────────────────────┴───────────────┘
行业 Top100 数量时间序列
口径说明
```

首屏中必须在不滚动或轻微滚动内看到：

- 当前模板名称。
- “固定 Top100”。
- 最宽行业。
- 5 日新进最多、退出最多行业。
- Treemap 主体。

不再显示：

- `0.80` 主提示卡、主图分隔线或“线上/相对偏低”标签。
- “当前宽度 / 最近变化”的面积切换按钮。
- 容易让人理解为买卖信号的“强/弱、涨/跌”主标签。

### 4.2 概览条

建议固定四项，每项都可被 30 秒测试读出：

1. `固定 Top100`：副文案“本模板每日 Pearson 排名前 100”。
2. `当前最宽`：`行业名 · N 只`。
3. `5 日新进最多`：`行业名 · +N 只`。
4. `5 日退出最多`：`行业名 · N 只退出`。

不要放“历史分位”“5 日均值”等会抢占首屏但不能回答本轮核心问题的指标。若保留，放到时间序列附近的次级说明。

### 4.3 Squarified Treemap

算法与几何要求：

- 使用标准 squarify 思路：按 `top100_count` 降序，在容器短边方向放置，使每组最大长宽比尽量小。
- 每个行业面积权重只取 `top100_count`。
- `top100_count = 0` 的行业不生成有面积的假块；在图下以“本日 0 只：行业A、行业B…”文本列出。
- 容器应有确定宽高，1440 建议高 480–540 px，1024 建议 430–500 px。
- 块间距 3–5 px，圆角不超过 5 px；过大圆角会削弱“面积比较”。
- 小块不强塞全部文字：面积不足时依次保留 `行业名`、`N只`；入选率移入 tooltip / focus 浮层。

块内信息顺序：

```text
行业名
N 只
入选率 x.x%
```

块背景使用同一中性色阶或模板弱色调，避免背景色暗示最近变化。数量越大无需再用颜色越深重复编码，因为面积已经承担数量。可以用轻微明度差帮助分区，但图例应明确“颜色不表示涨跌或变化”。

块的可访问名称应完整，例如：

`电子，当前 Top100 18 只，行业当日可选 142 只，入选率 12.7%，5 日新进 6、保留 12、退出 4`

hover / focus 浮层必须显示：

- 行业名称。
- 当前 Top100 数量与单位。
- 行业当日可选股票数（分母）。
- 入选率与计算式，例如 `18 / 142 = 12.7%`。
- 统计日期。
- 5 日新进、保留、退出。

点击后：

- 保持 Treemap 在原位，选中块加 3 px 深色内框和勾选标记。
- 页面平滑滚动到行业详情标题；键盘操作后将焦点移动到详情标题或首个股票行。
- URL 最好保留模板和行业参数，便于返回与刷新恢复，例如 `?template=...&industry=...`。

### 4.4 最近变化：颜色不是唯一编码

“最近变化”不应成为第二张改变面积语义的 Treemap。建议在 Treemap 下方详情区右侧放紧凑列表：

```text
最近变化（相对 5 个交易日前）
[＋] 新进入  6
    股票A  股票B  股票C ...
[＝] 保留   12
    股票D  股票E ...
[－] 退出   4
    股票F  股票G ...
```

每类同时具备：

- `＋ / ＝ / －` 符号。
- “新进入 / 保留 / 退出”文字。
- 数量。
- 不同实心、横线、空心形状。
- 辅助颜色。

页面概览中的“新进最多 / 退出最多”也使用完整文字，不只用蓝/橙箭头。变化定义旁明确“比较日期：当前日期 vs 5 个实际交易日前”，不要写含糊的“一周前”。

### 4.5 点击行业后的详情

1440 / 1024：

- 上部两列，左侧约 65% 是“当前进入 Top100”列表，右侧约 35% 是最近变化。
- 股票列表列为：排名、名称/代码、相似度、候选窗口日期、进入行情。
- 行业列表不需要再放迷你 K 线，以免和模板库主任务竞争；整行点击进入行情即可。
- 右侧最近变化列表可分三个可折叠组，但默认全部展开；每组顶部显示数量。
- 下部整行放该行业 Top100 数量时间序列，Y 轴单位明确“只”，X 轴显示完整日期 tooltip。

390：

- 顺序为“当前进入 Top100 → 最近变化 → 时间序列”。
- 股票行至少 64 px 高，名称/代码占一行，分数/窗口日期下一行。
- 新进、保留、退出使用三段式 accordion 时，默认展开“新进入”和“退出”，保留可以折叠，但标题与数量始终可见。

空态需区分：

- 当前行业 Top100 数量为 0。
- 5 日没有新进。
- 5 日没有退出。
- 行业分母缺失或不可追溯。分母缺失时入选率显示“—”，不能显示 0%。

### 4.6 响应式

| 尺寸 | Treemap | 详情 | 导航/控件 |
|---|---|---|---|
| 1440 | 单张全宽，约 500 px 高 | 65/35 两列 | 四模板同排 |
| 1024 | 单张全宽，约 460 px 高 | 60/40 两列；不足时上下堆叠 | 模板 2×2，保留完整名称 |
| 390 | 不改成普通卡片网格；保留真实 squarified 几何，容器约 420–480 px | 单列 | 模板横向滚动或 2×2；点击区 ≥44 px |

手机 Treemap 可采取以下降噪规则：

- 仅大块常显行业名与数量。
- 小块只显示 2–4 字简称或数量，点击/聚焦后在图下固定详情条展示完整信息。
- 不允许横向页面溢出；tooltip 必须限制在视口内。

## 5. 模板库

### 5.1 页面职责

模板库只负责浏览、分析和管理。顶部删除四字段创建表单，替换为单一主按钮：

`＋ 新建模板`

按钮进入 `/templates/new`。主标题副文案明确：

`查看冻结与自定义模板的真实历史 K 线，并逐只浏览相似股票。`

### 5.2 模板导航

1440：

- 左侧模板栏 240–280 px，右侧详情占剩余宽度。
- 冻结四模板与自定义模板分组清晰。
- 每个模板项显示名称、交易日数、冻结/自定义状态。
- 自定义模板的重命名和删除只在详情头或 `…` 菜单出现，避免左侧每行塞多个小按钮。

1024：

- 左侧栏 220–240 px；若详情宽度不足 680 px，改为顶部横向模板选择器。

390：

- 模板导航改为顶部可横向滚动的分组 tabs 或原生选择器。
- 当前模板名称与“冻结/自定义”状态必须常显。
- “新建模板”按钮与标题同区，不埋在列表底部。

### 5.3 模板详情真实 K 线

主图建议高：

- 1440：340–400 px。
- 1024：300–360 px。
- 390：280–330 px。

图表要求：

- 使用真实本地前复权 OHLC，显示蜡烛与成交量（若本地数据有量）。
- 标题直接写“模板真实前复权 K 线”。
- 模板起止边界用两条高对比竖线、起点/终点标签和窗口浅色遮罩共同表达。
- 图头显示 `来源股票 · 代码`、`起始 — 结束`、`N 个交易日`。
- 冻结模板同样显示真实来源窗口；只读状态用锁图标 + “冻结模板，只读”文字。
- 图下保留一句算法口径：`匹配时使用窗口内独立 z 与单窗口 Pearson；此图显示真实价格，便于判断阶段。`

不要：

- 用归一化线替代真实 K 线。
- 将模板起止仅写在图外，让用户自己找。
- 用未来区间延伸或事后涨跌标记解释模板。

### 5.4 Top 股票列表与迷你 K 线

1440 行结构建议：

```text
排名 | 名称 / 代码 / 行业 | 相似度 | 候选窗口起止 | 迷你前复权 K 线 | >
 32    minmax(180,1fr)      70       190             170×64
```

视觉要求：

- 行高 76–84 px，压缩现有横向留白。
- 相似度用 3 位小数，不用进度条制造绝对评分感。
- 迷你图是真实候选窗口 OHLC，不能使用随机或归一化折线。
- 迷你图至少有涨/跌蜡烛、窗口完整覆盖；不需要坐标轴，但应有 `aria-label` 描述起止日期。
- hover 时整行浅色高亮，focus 显示外环；整行点击进入行情页。
- 进入行情的链接保留 `template` 参数，并保留列表顺序/当前股票上下文。

1024：

- 迷你图缩到 120–150×58 px。
- 名称、代码、行业合并为两行；日期可换行但不截断到无法识别。

390：

- 每行改成两层卡片，顶部为排名 + 名称/代码 + 相似度，底部为日期 + 右侧约 128×54 px 迷你 K 线。
- 行整体最小高度约 112 px。
- 行尾箭头可省略，但整行点击语义与 focus 状态必须保留。

## 6. `/templates/new` 新建模板

### 6.1 单页工作流

页面应按步骤自上而下，不做多段优化器：

1. 搜索股票。
2. 展示完整真实前复权 K 线。
3. 拖拽左、右两个边界，框选一段历史窗口。
4. 显示起止日期、实际交易日数与窗口预览。
5. 输入模板名称并保存。

页面头提供明确返回：

`← 返回模板库`

保存成功后建议回到 `/templates?template=<new-id>`，新模板处于选中状态；不要停留在一张没有下一步的成功卡。

### 6.2 搜索

- 搜索框标签写“股票名称或代码”，支持键盘上下选择与 Enter。
- 结果显示名称、代码、行业。
- 选中后图表标题立即更新，并宣布“已加载 N 根本地前复权日 K”。
- 无本地数据、代码不存在、加载失败需分别提示。

### 6.3 双边界框选

这是本页的核心操作，不应复用行情页复杂画线工具。

- 初始窗口可默认落在最近一个合法长度（例如 60 个交易日），但必须清楚显示为“当前框选”，不能静默保存。
- 左右边界各有可见手柄，手柄视觉宽 2–3 px，桌面命中宽至少 14 px，触屏命中宽至少 32 px。
- 选中窗口保留正常亮度，窗口外加 35–45% 中性遮罩。
- 边界顶部标签显示起止日期；拖拽时实时更新交易日数。
- 键盘聚焦手柄后，左右方向键每次移动 1 个交易日；Shift + 方向键可移动 5 个交易日。
- 手柄不可交叉；到达另一边界或数据端点时停止并给出可读提示。
- 图表下提供可编辑的起止日期字段作为无鼠标替代，但它们与 brush 双向同步。

合法状态：

`2024-02-01 — 2024-05-10 · 66 个实际交易日 · 可保存`

不足 20 日：

`当前 17 个实际交易日，至少需要 20 个。请向外拖动边界。`

超过 240 日：

`当前 247 个实际交易日，最多允许 240 个。请缩短窗口。`

错误必须同时出现在：

- 图内窗口顶部/底部的状态标签。
- 日期与名称表单附近。

但不要用纯红色整片覆盖 K 线；使用图标、文字和边框辅助。无效时保存按钮禁用，并保留禁用原因。

### 6.4 预览与保存

图下固定摘要建议：

```text
起始日期        结束日期        实际交易日数
2024-02-01      2024-05-10      66 日

模板名称 [__________________]
[保存模板]
```

- “预览”可以是主图中高亮窗口的放大副图，使用相同真实 K 线，不需要再做抽象线。
- 名称最多长度和必填状态就地显示。
- 保存期间按钮文字改为“正在保存…”，防止重复提交。
- 冻结模板不进入本流程；自定义模板保存后可在模板库改名/删除。

### 6.5 三尺寸布局

| 尺寸 | 布局 |
|---|---|
| 1440 | 搜索与状态在顶部；主图 440–520 px；图下摘要与命名区同排 |
| 1024 | 主图 400–460 px；摘要 3 列，名称与保存下一行 |
| 390 | 主图 330–390 px；搜索、摘要、名称单列；手柄命中区 ≥32 px；保存按钮满宽 48 px 高 |

手机必须禁止 brush 操作触发页面横向滚动；图内横向拖动与页面纵向滚动的手势边界要稳定。

## 7. 行情页：纯行情与两档紧凑模式

### 7.1 保留与删除

保留：

- 真实行情 K 线。
- 右侧模板列表。
- 上下键切换模板股票。
- 模板与候选窗口真实 K 线对照。
- `← 返回模板库`，并保留当前 template 参数。

删除：

- “保存区间”。
- “保存当前区间为模板”。
- 任何将当前行情区间写入模板的快捷入口。

### 7.2 一键紧凑 / 展开

在行情页顶部工具区常驻一个文字明确的两态按钮：

- 展开态：`收起顶部`，图标向上，`aria-pressed="false"`。
- 紧凑态：`展开顶部`，图标向下，`aria-pressed="true"`。

不要只放一个无文字 chevron。按钮点击区至少 40×40 px，390 下至少 44×44 px。

两档定义：

| 区域 | 展开 | 紧凑 |
|---|---|---|
| 顶部搜索/工具 | 约 58–69 px | 约 48–52 px，保留搜索入口与展开按钮 |
| 股票摘要 | 约 170–190 px，完整字段 | 约 64–80 px，只留名称、代码、最新价、涨跌、日期 |
| 次级估值/数据日期 | 展示 | 隐藏或收进“更多” |
| K 线可视高度 | 基线 | 至少增加 100–140 px |

可靠性要求：

- 模式切换不丢失当前股票、template、候选窗口、右栏滚动位置。
- 图表在过渡完成后正确 resize，不出现空白或蜡烛挤压。
- 模式最好记入当前会话或 URL，但不是保存模板。
- 1024 右栏可抽屉化，紧凑按钮仍在主内容可见。
- 390 默认可采用紧凑态，但首次进入必须让用户看得懂“展开顶部”的含义。

### 7.3 模板与候选窗口对照

右侧对照区应从抽象双线改为两个真实小 K 线：

```text
模板窗口                     当前候选窗口
真实前复权 K 线              真实前复权 K 线
起始—结束 · N日              起始—结束 · N日
                              相似度 0.xxx
```

要求：

- 两图各自使用自己的价格轴，不把绝对价格强行共轴。
- 图题清楚写“模板窗口”“候选窗口”。
- 两边都标出起点、终点与完整窗口。
- 可加阶段观察文案，例如“候选窗口当前更接近模板的起涨段/加速段/末端形态”，但若系统没有可靠阶段分类，不自动给阶段结论，只让用户基于 K 线判断。
- 固定说明：`相似度只比较两个窗口内的形状，不代表后续走势。`

### 7.4 抛物线阶段解释

页面与交付文案建议：

`当前结果中有些候选窗口视觉上更接近模板的前段，这只说明被选窗口与模板窗口的局部形状接近。它不能说明市场中已没有抛物线行情，也不构成对后续阶段的预测。真实模板 K 线、候选 K 线和起止边界用于帮助人工判断匹配处在起涨、加速还是末端。`

禁止：

- “市场已无抛物线行情”。
- “该候选之后会进入加速/末端”。
- 用窗口结束后的未来 K 线、收益、IC 或策略表现验证。

## 8. 返回路径与上下文

所有跨页动作都要可逆：

| 起点 | 目标 | 必须保留 |
|---|---|---|
| 模板库 Top 股票 | 行情页 | `template`、股票代码、模板列表顺序 |
| 行业详情股票 | 行情页 | `template`、股票代码、行业上下文（可选参数） |
| 行情页 | 模板库 | 当前 template，模板库恢复选中和滚动位置 |
| 模板库 | 新建模板 | 明确返回模板库 |
| 新建成功 | 模板库 | 新模板 ID，详情直接选中 |

行情页右侧模板列表切股后，只替换股票代码，不丢失 template。浏览到列表首尾时按钮或键盘动作要有边界反馈，不循环跳转除非界面明确说明。

## 9. 30 秒可理解测试

测试者不阅读说明文档，只看页面。计时 30 秒，必须能口头回答或完成：

### 行业宽度页

1. 当前模板是什么？
2. 这张图每天取多少只股票？
3. 当前 Top100 行业最宽是谁、多少只？
4. 相对 5 个交易日前，新进入最多和退出最多的行业是谁？
5. 点一个行业后，当前进入 Top100 的股票在哪里？
6. 新进、保留、退出分别在哪里，且不看颜色也能分辨吗？
7. 如何进入某只股票的行情？

### 模板库与新建页

1. 如何进入新建模板？
2. 当前模板是真实 K 线还是抽象线？
3. 模板窗口起点、终点和交易日数在哪里？
4. Top 股票的候选窗口在哪里预览？
5. 新建页如何用两个边界框出一段窗口？
6. 19 日或 241 日时，为什么不能保存？

### 行情页

1. 如何回到当前模板的模板库？
2. 如何逐只浏览模板股票？
3. 模板窗口与候选窗口分别是哪张图？
4. 如何一键收起顶部，让 K 线更高？
5. 页面上是否还存在保存模板入口？正确答案应为“没有”。

任一核心问题超过 30 秒仍找不到，优先修正信息层级和按钮文案，不用增加更多说明卡。

## 12. 设计验收优先级

### P0：不满足即不能交付

- Treemap 面积固定为当前 `top100_count`，且为真正 squarified 布局。
- 主页面不再以 0.80、线上/相对偏低为主语义。
- 入选率写明分母、单位与日期。
- 新进/保留/退出有非颜色编码。
- 行业点击后有当前 Top100 股票和三类变化列表。
- 模板主图、候选缩略图、创建预览、行情对照均为真实本地前复权 K 线。
- `/templates/new` 有双边界 brush 与 20–240 实际交易日就地校验。
- 行情页移除全部保存模板入口，并提供可读的两档紧凑控制。
- 三尺寸无关键遮挡、横向溢出或死按钮。

### P1：显著影响可用性

- 30 秒测试全部通过。
- 跨页返回恢复 template 与列表上下文。
- hover、focus、键盘、点击区和对比度满足本规范。
- 手机 Treemap 小块和 brush 手柄可稳定操作。

### P2：可在不改变口径的前提下优化

- 记忆行情紧凑状态。
- 记忆模板库和行业列表滚动位置。
- 小块详情固定条与 tooltip 动画细节。
