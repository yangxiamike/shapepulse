# 已确认的界面方向

确认日期：2026-07-16

## 01 本地行情终端

对应图片：`01-local-market-viewer-approved.png`

- 定位为独立、通用的本地行情查看工具，不和形态筛选强绑定。
- 支持按股票名称、股票代码、拼音首字母搜索。
- 主要能力包括 K 线、成交量、周期切换、指标、画线、自选和多布局。
- 为后续接入因子研究、交易系统和更多分析模块预留入口。
- 可以从选股看板打开指定股票，也可以独立搜索和使用。

## 02 综合选股看板

对应图片：`02-stock-screening-dashboard-approved.png`

- 专门负责股票池过滤、形态初筛、Top 50 排名和每日人工复核。
- 股票池条件包括板块、市值、是否剔除 ST，默认 Top 50。
- 三类形态为：突破启动、上升趋势回调、区间下沿反弹。
- 保存已查看、已保存、待判断和历史筛选记录。
- 点击候选股票或“打开行情”进入独立行情终端。

## 统一视觉语言

- 页面结构分别参考 04 号看盘界面和 06 号综合终端。
- 使用 02 号的暖白、近黑、薄荷绿、荧光黄和电光蓝配色。
- 吸收 09 号清晰、直接、有反馈感的操作方式，但保持专业、克制。
- 强调字体层级、黑色边框、模块化网格和清楚的数字信息。

## 开发边界

选股看板与行情终端共享股票代码和跳转入口，但保持功能解耦。形态筛选属于选股看板；通用行情、指标、因子和未来交易能力属于行情终端。
